# Aetherion — zakres pierwszej wersji

## Filary
- Autorskie uniwersum Aetherion i energia Eterium.
- Pięć ras: Terranie, Varkari, Elarianie, Sylvari, Noctari.
- Mobilne sterowanie dotykowe, kamera top-down i czytelna walka.
- Najpierw offline PvE; multiplayer dopiero po ustabilizowaniu gry.

## Pierwszy pionowy wycinek
- Wybór rasy, start w Kamiennym Kręgu.
- Ruch, atak podstawowy, technika obszarowa i Przebudzenie Rdzenia.
- Przeciwnicy, HP, XP, poziomy, złoto i drop.
- Zadanie startowe, NPC, ekwipunek, mikstury i zapis lokalny.
- Testowy build Android przez GitHub Actions.

## Poza zakresem pierwszego wycinka
Serwer, konta online, gildie, czat, handel między graczami, otwarte PvP, pełna mapa planetarna, ekonomia online i wojny gildii. To będą osobne etapy.

## Zasady projektu
Nie kopiujemy nazw, postaci, światów, muzyki ani assetów z istniejących marek. Nie deklarujemy działającego builda bez potwierdzenia w GitHub Actions i testu na urządzeniu.
