# Aetherion — KI: Legends of Power

Projekt gry 2D pixel-art top-down na Androida, tworzony w Godot 4.x / GDScript.

## Plan
1. Grywalny offline PvE.
2. Rozbudowa świata, ras, questów i walki.
3. Testy Android i stabilny APK.
4. Backend autorytatywny i multiplayer jako późniejszy etap.

Szczegóły: [README_PL.md](README_PL.md) oraz [GDD_SCOPE.md](docs/GDD_SCOPE.md).

**Status:** prototyp źródłowy. APK nie jest uznawany za gotowy, dopóki workflow CI nie zakończy się powodzeniem i aplikacja nie zostanie sprawdzona na urządzeniu.
